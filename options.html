Domain Rating Lookup

This extension calls Ahrefs’ domain-rating-free endpoint. Requests are free of API units and require a free APIv3 key.

Create a key in Ahrefs → Account → API keys. Stored only in this browser via Chrome local storage. Never sent anywhere except api.ahrefs.com. Saving checks the key with a lookup of example.com.

Toolbar badge

One per line; subdomains are included. Local and private hosts (localhost, IP addresses, .local, .internal) are never sent to Ahrefs.
