# Chrome Web Store listing (pointer)

Canonical store prep lives in [`CHROMEWEBSTORE.md`](../CHROMEWEBSTORE.md) at the repo root.

Use that file for dashboard copy-paste: name, descriptions, permissions, privacy disclosures, asset paths, and submit blockers.

Supporting assets:

- Screenshots: `store/screenshots/`
- Small promo tile: `store/promo/small-promo-440x280.png`
- Privacy (markdown): `store/PRIVACY.md`
- Privacy (HTML for hosting): `store/privacy.html`
- Package: `dist/domain-rating-lookup.zip` via `npm run package`
